# 物体图片管理
在“姿态与动作 → 物体参照”选择已存物体编号，点击“图片管理”。左侧列出该编号的全部有效视角，★初始帧固定第一位，提供原始位姿基准；右侧显示大图、拍摄时间、初始参照XYZ及当前视角的几何关联状态。可取消“显示分割轮廓”查看原图。

选中补录帧，点击“删除选中补录视角”并确认，该帧立即从图片列表和后续匹配候选中移除；不重启视觉进程也会刷新缓存。历史不可变快照保留，原始帧和已有动作参照不改写。初始帧不能单独删除；若整件物体不再使用，可在主页面删除物体记忆。

新增 visual_reference_gallery.py（无ROS界面），扩展 visual_reference.py 的有效视角索引和删除，visual_action_panel.py 增加入口，visual_action_worker.py 按有效图片ID刷新缓存。现有动作执行及抓取运动链路未修改。


# 矩形框录入（新物体及补录共用）
新建：填写名称 → 取景框选新物体 → 在大图拖框包住整个物体 → 查看分割轮廓 → 确认轮廓并保存。
补录：选择旧编号 → 给所选编号补录 → 在大图拖框 → 确认保存。原编号与初始位姿不改变。
框选后只生成预览，不会自动写入记忆；不满意可在同一帧重新拖框。矩形框是SAM2提示，保存的是实际分割mask及配对RGB-D，不把整个矩形当作物体。关闭大图不自动保存。后续重新识别也利用已匹配整物体表面的投影框进行分割，避免重新只分出标签。全新未见表面仍需足够共同几何才可用于精确纠偏。
