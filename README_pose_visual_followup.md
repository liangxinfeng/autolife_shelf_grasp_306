# 物体补录与姿态同步修正（2026-11-10）

## 操作

在“姿态与动作 → 物体参照”选中已记录的编号，再点“给所选编号补录”。可以先移动或转动物体，取景时让机器人和物体停住，点图中的同一物体即可。新视角追加在原编号下；第一帧位姿、原始文件和已有姿态绑定不变。

能匹配共同表面的新视角会自动转换到第一帧参照坐标。不重叠的面也保存整块分割RGB、深度、点云和外观特征，但标为“外观已存档，未关联初始几何”。补录同时包含旧面和新面的过渡视角后，定位时会再次尝试关联这些已存视角。不能凭外观识别就伪造初始坐标关系。旧参照、原有动作和任务调用格式兼容，仍沿用既有200mm/30度局部纠偏范围。

## 运动修正与边界

原末端IK/镜像执行将七关节分别交给组目标追踪；普通姿态串在曲线下发时又对各轴单独裁切，破坏了肩、肘、腕的共同进度。最新记录中，某次前伸约145mm、起终点高度相近，按URDF计算实测中间下降约95mm；相同起终点的同步关节曲线约下降9mm。这是坐标模型计算，不是外部测量。

多轴末端IK/镜像现在调用已有姿态执行器，普通姿态串按照同一C2曲线、同一进度发送。某轴达到反馈提前量上限时，整段共同减慢，其他轴不继续跑到前面。GUI调度间隔变长不追跳到远处目标。保留速度、关节范围、反馈、通信、到位期限及停止；不提高电机增益，不改变已有保存的关节终点。未选身体部位在执行前采用新鲜反馈保持，夹爪保持已执行意图。

这里改正的是关节同步与输出失真，不把关节空间曲线宣称为严格笛卡尔直线。不同电机的实际跟踪仍需现场验收；连续录制轨迹保持原时序，身体高度单独控制和单关节调节不改变。

## 文件

- visual_multiview.py：不同位置视角归档、初始几何关联、过渡视角关联、仅外观候选的像素检索。
- visual_action_worker.py / visual_registration.py：整块分割观测与纠偏使用，原始锚不变；无纹理面可归档，不生成假对应。
- visual_reference.py / visual_action_panel.py：原编号追加、视角状态与中文操作提示。
- pose_synchronized_output.py：共同进度、整段反馈限制、按同步曲线输出。
- pose_execution_bridge.py：接入已有姿态执行器；原时序录制不改。
- pose_workspace_motion.py / action_studio.py：末端IK和镜像的多轴执行走共用曲线，保持未选部位。
- test/test_visual_followup.py：移位、旋转、原始快照不变、无重叠归档、同步进度与不同响应速度回归。

本次不修改用户姿态/动作/参照文件，不重启原厂机械臂服务，不自动使能或运动。安装后重开程序生效。
