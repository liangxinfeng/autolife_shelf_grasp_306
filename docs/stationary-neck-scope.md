# 静止颈部与独立手臂路径分离

保留用户保存的约30°颈部姿态，不修改URDF、SRDF、关节限位或保存目标。

普通抓取、观察、放置及复位规划开始时，绑定本次起点。仅将起点已存在的 `Link_Waist_Yaw_to_Shoulder_Inner_0 ↔ Link_Neck_Pitch_to_Neck_Yaw_0` 作为静态模型告警，条件是该路径腰腿和颈部保持原值（0.05°只容纳保存/反馈量化差异）。独立手臂继续检查与全身的碰撞，含头颈；所有其他碰撞仍阻止该路径。

复位只有在目标腰腿、颈部与起点相同的情况下适用。若要改变颈部/身体角度，则恢复完整碰撞检查，原有受支撑的颈部抬离流程保留。不能将此能力理解为允许任意低头或允许手臂碰头。

每次重新绑定都会清空检查缓存，旧路径的静态告警不传递给新路径。没有绑定的碰撞检查默认保持严格。识别、显示、姿态/动作编辑本身不会被该静态颈胸模型重叠禁用。没有执行任何自动使能或测试动作。
