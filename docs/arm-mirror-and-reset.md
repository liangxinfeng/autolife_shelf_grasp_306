# 双臂镜像与全身复位

“姿态与动作 → 调姿态 → 双臂镜像”提供两个方向：左臂→右臂、右臂→左臂。

1. 先将来源手臂在实机上调好并停稳。
2. 选择镜像方向，点击“生成镜像预览”。模型显示目标侧的蓝色虚影，不发送运动。
3. 点击“执行镜像姿态”，只执行目标侧7个手臂关节。来源手臂、腰腿、头部和两侧夹爪开度不变。
4. 可使用原来的“保存蓝色编辑预览”保存结果，或执行后保存实机姿态，再组合动作串。

镜像符号根据本机URDF关节轴与安装位置推导。本机7轴顺序的符号为 +、−、−、+、−、−、+；若模型变更后不满足左右对称安装条件，会停止计算，不硬套符号或裁剪超限角度。运动前检查目标侧手臂路径。

全身复位仍引用 `manual_reset_pose.json` 中的已保存目标，使用共用姿态速度。`workspace_reset_bridge.py` 提供复位进程专用的腰腿开放和动作启动方法，调用正式关节桥；不再经过标定工具禁止腰腿与动作串的入口。普通标定/抓取的ROS入口限制未改变。保持使能、SYNC、通信和停止机制继续生效。
