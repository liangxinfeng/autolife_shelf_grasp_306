# 抓取几何默认使用本机URDF

`config/grasp.yaml` 的 `geometry_source: urdf` 是默认模式。识别、左右手规划、路径投影、持物后的放置和执行前一致性检查统一走 `grasp_geometry.py`，无需左右手 `session.json`，不比较历史标定的相机分辨率或内参。实时深度仍使用当前相机提供的内参。

相机使用本机URDF的额头安装链和现有RGB光学轴约定；每帧使用配对关节反馈做正解。夹取中心使用同一URDF手指参考点的中点，与末端IK示教一致；不叠加旧标定板到TCP的15毫米偏移。左右手手动补偿仍有效。

这是名义几何，并非实测手眼标定。尤其345的DM夹爪与名义URDF工具可能有机械尺寸差异；需要时按实物误差调整左右手补偿。已实测的DM夹爪开口—电机位置映射仍保留，它用于开合控制，与手眼标定文件是不同数据。

`grasp_collision.py` 去掉普通抓取中不适用的标定板包络检测。原有实体模型碰撞对、限位和携物包络仍检查；手眼标定工具自身没有修改。如果保存的复位姿态本身颈胸相交，仍需调整复位目标，不能靠删除标定板包络放行。

旧的按标定生成的抓取计划不能跨模式继续执行，需要重新识别/规划。用户姿态、动作和语音数据不会被覆盖。旧标定文件保留，但默认不读取；只有显式改为 `calibrated` 才使用。
