# 姿态执行与抓取复位

1. 在“姿态与动作”中将实机调到期望姿态，点击“将当前姿态设为复位姿态”。保存包含腰腿、双臂、头部和左右夹爪的23轴实测状态。保存本身不运动。
2. “姿态 / 复位速度”同时作用于执行已保存姿态和抓取页全身复位，范围25～100%，默认40%。改变后自动保存，下次启动继续使用，不必重新保存复位姿态。
3. 返回抓取页点击“复位并准备”。身体关节先到位并停稳，然后恢复保存的左右夹爪开度。
4. 没有明确设置全身复位姿态时，会提示设置位置，不自动使用原来的双臂默认目标。

两处共用 `pose_execution_profile.py` 的单姿态时序和 `pose_execution_bridge.py` 的原厂动作输出适配。复位不再叠加原来的Follower与逐组apply目标；原厂电机响应参数未修改。

复位执行前仍检查全身路径。颈部低垂贴身时，原有经人工支撑确认的慢速抬头步骤保持原速，不跟随普通姿态速度提高。停止、反馈断开、SYNC失败不会登记为复位完成。

文件：
- `data/fixed_actions/manual_reset_pose.json`：用户设置的全身复位姿态。
- `data/fixed_actions/manual_pose_settings.json`：两处共用的速度百分比。
- `workspace_reset.py`：读取复位目标、检查路径及生成共用姿态动作。
- `pose_reset_execution.py`：在抓取执行进程中运行该动作，复用原来的停止与心跳机制。

同起点、同目标、同速度的轨迹时序和输出算法一致；使能准备、路径检查、实际电机负载仍会影响总耗时。本次安装只做无动作软件验证，未自动运行复位。
