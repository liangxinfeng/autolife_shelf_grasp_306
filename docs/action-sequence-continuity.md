# 编动作：连续通过与逐帧纠偏

## 操作

1. 打开“姿态与动作 → ② 编动作”，载入已有动作，或添加已保存姿态。
2. 点击“全部连续通过”，将各帧停顿设为0秒；新添加姿态默认0秒。需要停留时，选中该帧再改“选中姿态停顿”。
3. 列表中带物体关联的姿态有复选框：勾选启用纠偏，取消只暂停这一帧，不删除绑定。可以随时勾回，保存、重新载入、上移/下移后状态仍保留。
4. 没有关联物体的姿态显示“固定姿态”。要新增物体关联，先在调姿态中关联并保存，再添加到动作串。
5. 保存动作串后，模型预演、真机运行、任务按名称调用采用同一停顿与纠偏设置。执行期间不可编辑；停止后可继续修改。

## 运动语义

普通零停顿中间点采用共同进度的C2曲线衔接，不增加到位停留；下一控制周期直接推进下一段。反向运动仍需自然减速过零，不承诺关节始终有非零速度。最后一个姿态仍停稳。

保留夹爪交互约定：若此帧需要改变夹爪目标，先让身体/手臂到位停稳，再开合夹爪，然后继续。不会因“全部连续通过”提前松开物品。连续VR录制轨迹保持录制时序。

不增加速度/电机响应，不放宽限位和跟随约束，也不改历史动作数据。原有动作须在界面按需点击“全部连续通过”并保存。
