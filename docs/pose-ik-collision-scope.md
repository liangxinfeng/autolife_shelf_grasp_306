# 姿态页末端IK的碰撞范围

末端IK只允许所选手臂7轴改变。每次计算绑定当前全身状态，腰腿、头部、另一臂和夹爪开度必须保持；改变这些部位后需要重新取当前末端。

`pose_collision_scope.py` 根据模型关节父子链确定随所选手臂运动的几何对象。所选臂与躯干、头部、另一臂、另一只夹爪及自身之间的模型碰撞仍会阻止预览。两个不随本次手臂动作运动的对象之间的重叠只作固定部件提示，不再导致单臂方向调整全部失败。抓取与全身复位仍使用原来的全身检查。

计算前对照官方URDF与碰撞模型的身体连杆变换，安装关系不一致时报错。模型夹爪沿用本机已有简化几何，不能把DM夹爪电机位置量当成手指角；姿态IK没有挂载标定板，不附加原手眼标定用的虚拟球。

此次复现：颈部俯仰约25.04°时，胸部与颈部模型重叠，左右手六个平移方向都被旧检查拦住。原厂完整URDF同样存在该重叠，不能声称物理上一定无碰撞。新版显示该固定部件提示，同时独立核对手臂运动。

已保存的“原初始复位姿态”来自之前成功复位的目标和完成回执，不是此次实时姿态。全身复位目标包含23轴；以后点击“将当前姿态设为复位姿态”可重新指定。
