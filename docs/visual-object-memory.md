# 动作物体记忆与纠偏（2026-11-10）

## 使用

1. 在“姿态与动作 → 调姿态 → 物体参照”取景，拖框选择整个物体并确认分割。初始帧确定动作的物体位姿基准。
2. 选择已有物体编号保存姿态即可，不要求保存姿态时物体仍在画面内。相对关系使用最初记下的物体位置；示教应在这个初始摆放位置建立。
3. 换角度或位置后，可在原编号下补录外观，图片列表可查看初始帧、删除补录视角。补录不覆盖初始位姿，也不改变已保存动作。
4. 编动作选择姿态，纠偏按钮可开/关；开启时使用姿态原有绑定。准备、收回等固定姿态可不纠偏。
5. “定位参照并预览纠偏”会显示当前完整分割轮廓、纠偏量、模型预演；整物体检索成功时显示“整物体外观记忆识别”。真机运行及任务调用仍会重新观察当前场景。

已有物体图片会自动生成外观特征，不需要删除重录，也不需要导入商品库。只纠正位置不会强行估计圆瓶绕轴方向；需要姿态修正时选择位置＋朝向，并由三维对应验证旋转。

## 本次原因与修正

此前动作纠偏主要用SIFT纹理点完成物体发现和3D配准，身份识别也被纹理/深度有效点数量绑住。标签转动、反光和局部深度缺失会导致整物体仍可见却认不出。

现流程：GroundingDINO/SAM2整物体候选 → 同一分割灰底预处理 → 现有DINOv2特征 → 与初始及有效补录视角比较 → 选定实体 → 深度/纹理定位 → 所选臂IK → 平滑路径检查。模型复用已有视觉进程，不新开相机，不加载第二套模型。

每个物体取最佳已录视角分数，不平均正反两面而压低匹配；删除或补录后缓存自动失效。默认相似度/实例间差值复用grasp.yaml中的match_threshold和match_margin，不新增需要现场调试的阈值。通用检测未覆盖的物体仍可使用原纹理定位。

外观相似不等于位姿可靠：补录未配准也可增强身份识别，但其拍摄位置不能充当初始动作坐标。位置计算仍相对最初RGB-D；无法可靠旋转时不生成虚假旋转。多个相同外观实体、目标不在画面或缺少可靠深度会明确提示，而不会把背景当成目标。

## 验证与范围

270项无动作回归通过，包括多视角评分、删除失效、同类多实例歧义、外观/几何分离、旧动作及任务执行回归。4份已有视角与此前失败RGB-D均识别通过；失败画面相似度0.976，其他候选0.37～0.47。三维位移约[-13.9,94.6,4.4]mm，配准残差5.73mm；保存姿态逆解与115个路径状态通过，非所选手臂目标保持不变。相似度不是概率或绝对定位精度。

当前现场画面没有水瓶，已验证无目标不误生成动作；本次未运动。仍需在实际目标前预览并验收，不能将以上回放等同所有场景真机通过。

局部纠偏范围沿用200mm/30°，只重算所选七轴；不改腰腿/另一侧臂/夹爪目标，不改原厂速度、使能与保持服务。连续录制保持原时序，纠偏功能用于带绑定的姿态串。

## 文件

- visual_object_memory.py：复用DINOv2、多视角缓存、实体检索；无硬件接口。
- visual_action_worker.py：识别、深度定位、IK及路径预览；失败诊断保留当前运行目录。
- visual_action_panel.py：显示整物体识别与定位方式。
- test/test_visual_object_memory.py：检索与旧流程隔离回归。
- data/fixed_actions/visual_references：用户初始/补录RGB-D及index；与姿态、动作库一起迁移，不包含在公开源码快照中。

README_visual_actions.md及其他README_pose_visual*.md是各阶段说明；保存姿态不再要求当场识别，整物体识别流程以本说明和当前代码为准。
