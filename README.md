# 345 · 抓取与任务流程

分支 `robot345-20261109` 保存345机器人2026年11月9日已安装的功能包源码。在原 `robot306-20261013` 历史上新增分支，不替换原有版本。ROS包名仍为 `autolife_shelf_grasp_306`，以兼容现有启动器和调用方。

## 功能

- Grounding DINO + SAM 2检测与分割、RGB-D目标几何、左右手抓取和放置；支持不先录入商品库的可见目标。
- 默认采用本机URDF的相机与工具关系，保留显式手眼标定选项；支持左右手独立位置补偿、抓取速度调节和DM夹爪开口映射。
- 姿态与动作：全身关节调节、末端IK示教、左右臂镜像、保存姿态、全身复位目标及动作串。
- 遥操动作编辑器：关键姿态、连续轨迹录制、预演及回放。
- 导航与航点、语音、视觉抓取、动作及放置的任务编排。

## 本次最新修正

1. 复位前通过原厂进程刷新实际关节位置，避免把停用期间旧反馈当成当前姿态；使用保存的全身复位目标。
2. 抓取收回结束、放置开始和暂停交接保留夹爪当前夹持指令；到达放置阶段后才按流程松开。
3. 允许以有效可见瓶身生成几何，不再要求先完整入镜。仍核对抓取区域深度、夹爪可用宽度及路径；瓶底已观测时支持对应放置计算，缺失部分不伪装成实测尺寸。
4. 原厂IK规划器复用已加载模型，路径仍针对当前状态重新检查。

本机配置最大夹爪净开口为 **90毫米**；开口映射见 `config/gripper_width.json`。配置保留345的实际路径和参数，这是机器版本快照，不能直接视为其他机器人通用标定。

## 运行环境与外部依赖

现用Ubuntu 24.04 / ROS 2 Jazzy，系统Python运行ROS/Qt界面，`s3_perception`环境运行视觉与运动学，`robot_env`运行厂商机械臂服务。需已有相机、雷达、模型资源及相关控制中心、遥操模块；依赖声明见 `package.xml`，补充见 [部署依赖说明](docs/DEPLOYMENT_345.md)。

**本仓库是源码分支，不是一键离线安装包。** 不包含模型权重、厂商SDK、用户照片/商品库、现场地图、个人姿态/复位/动作/任务数据。实际保存的复位姿态属于 `data/`，需在原机器保留或另行迁移。

在已经具备上述环境的机器上构建：

```bash
cd ~/ros2_ws/src
git clone --branch robot345-20261109 https://github.com/liangxinfeng/autolife_shelf_grasp_306.git
cd ~/ros2_ws
source /opt/ros/jazzy/setup.bash
colcon build --packages-select autolife_shelf_grasp_306 --symlink-install
source install/setup.bash
ros2 run autolife_shelf_grasp_306 shelf_grasp
```

已有同名目录时不要覆盖现场数据。最新的夹持交接和反馈刷新需要配套原厂服务扩展，见 [接口与补丁](integration/vendor_20261109/README.md)；构建ROS包不会自动安装或重启这些服务。
