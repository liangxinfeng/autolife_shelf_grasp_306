# 306 桌面物品抓取实验

## 2026-09-16：小角度接近与自然收回（最新）

- 正向夹取优先。折叠起点沿直线去预抓点若碰自身，改试全限位内的预抓点IK及连续关节空间路径；该路径仍逐点检查，不直接跳到远端IK解。
- 抓取和抬起仍沿原路径；收回前6cm保留朝向，之后4cm逐步释放方向约束，由解析雅可比有界最小二乘自动选择手腕朝向，不再枚举12个固定收回角度。优先保持瓶子直立，额外倾斜上限约15°；需要严格竖直的开口容器不适用此实验流程。
- 夹入角度与收回方向解耦，界面显示“接近X° · 自然收回”。位置误差4mm门槛、厂商有效关节限位、平滑轨迹0.1°采样检查、自碰撞/携物包络和执行保护不变。
- 6cm并不代表已检测到货架外侧；仍未检查货架、桌面和邻物，确认前必须检查整个预抓取/收回空间。新预抓路径可能弯曲，不保证无外部碰撞。
- 规划界面秒数现在包含重新识别、深度检查和规划，总计耗时及分阶段计时保存在规划文件 `timing_seconds` 中。小型IK矩阵使用单线程BLAS，限于后台进程，不修改系统环境。
- 本轮15份现场目标离线回放全部通过；上层雪碧/农夫山泉/冰红茶从20°/25°/30°改为0°接近。实时只读链路测试约2.57/1.52/1.65秒（雪碧含首次模型加载）；复杂下层冰红茶约3.38秒，不承诺任意目标或系统负载下都小于3秒。模型误差不是实物抓取精度，尚未自动执行真机抓取验收。

以下保留历史版本记录；收回朝向及耗时显示以本节和当前代码为准。

独立功能包：`autolife_shelf_grasp_306`。针对**空旷桌面、左臂侧向抓取**，支持瓶罐、尺寸已知的非圆柱实体及人工选点的袋口。保留原商品库，不修改遥操、导航、标定或厂商服务。

## 新物品怎么用

界面顶部有两种模式，可切换并记住选择：

- **仅饮料**：只运行瓶/杯类YOLO检测，不运行FastSAM通用分割。未知瓶杯仍需人工确认，不能保证分类模型绝无误检。
- **通用物品**：保留YOLO + FastSAM，匹配全部商品库。

**两种模式共用同一个商品库、ID、尺寸和样本。**在通用模式录入的饮料，切到仅饮料后无需重录；反过来也一样。模式只改变检测入口，不筛掉另一模式录入的商品资料。

右侧“商品库”支持选商品→修改名称、类型、宽度、高度及厚度；只保存参数不新增图片。可以查看样本缩略图、删除选中样本，也可在主界面选好物体后追加当前图像。同名录入现在更新参数并追加照片，不再因为尺寸不同拒绝更新。尺寸会显示在主列表中；宽50、高80分别保存为0.05m、0.08m，不混用。

删除样本同时移除对应DINO特征；最后一张也可删除，但该商品暂不能自动匹配。历史商品库留在`data/history/`，原图保留以便恢复，不再参与活动匹配。参数/样本/模式变化使旧规划失效，需重新预览。

1. 点击“识别物品”，选中完整物品区域，再“录入商品”。新物品需要录入名称和实测尺寸，不能仅凭通用分割自动知道商品名称。
2. 口香糖罐选“瓶罐/圆柱”，填写直径、高度。西瓜模型选“非圆柱实体”，填写宽度、高度、当前可见面至背面的厚度；定位使用可见中部加半厚度近似，并非任意形状的精确重建。
3. 袋子选“袋口边缘”，填写袋体宽、高及袋口局部厚度；点击“选择袋口夹取点”，在快照上点实体袋口，避开细提绳。每次重新识别后重新选点，轮廓变化过大则要求重选。袋子不能用整袋中心抓取。
4. 先复位、规划预览，再由用户确认抓取。夹取位置仍使用当前标定、TCP和向机器人右侧15mm的经验补偿。夹爪闭合稳定后自动抬起收回；程序不会自动替用户启动运动。

分割为 YOLO11 + FastSAM-s 候选，DINOv2仍负责已录入商品匹配。通用分割也可能出现纸盒、家具等候选，必须确认所选轮廓。只在识别/规划请求时推理，不在RGB预览线程持续运行；最多12个候选。不保证所有柔性袋、反光或透明物品都可识别、定位和抓稳。

## 启动

```bash
~/grasp306
# 或 source ROS 与工作空间后：
ros2 launch autolife_shelf_grasp_306 grasp.launch.py
```

1. 启动系统视觉服务和机械臂服务；本程序不会重启、自动使能或复位硬件。
2. 每轮实际抓取前先“复位并准备”：点击后检查路径，检查通过立即进行保持式使能并执行一次连续复位，无二次弹窗。使用手眼标定的VR初始关节姿态，双臂及头部回位，腰腿保持，同时将双夹爪开到系统开端10°。**点击前取走双爪内物品并清空双臂运动空间。**启动程序本身不会复位。
3. 复位完成会清除旧目标并重新识别物品。也可单独点击“识别物品”进行只读实验。实时画面切为可选识别快照。
4. 选中物品，“录入商品”填写名称、类型、实测尺寸。界面中的尺寸只是输入初值，**必须按实物修改**。同名录入补充样本；建议从多个朝向采集6～12张，不是必须每次训练YOLO。
5. 选中已录入饮料 → “规划预览”。**不需要设置支撑面。**使用瓶身分割、深度和直径拟合水平中心，完整可见瓶身的上下边界中点作为抓取高度；瓶高只做完整性校验。不将单个可见表面点直接当作瓶子中心。
6. 重新确认目标并做5帧一致性检查，预检预抓取、抓取、抬起、收回完整路径。抬起方向来自当前URDF运动学，不假定躯干+Z向上。真实抓取要求本轮复位完成凭据，使用一次后失效。

全开到位容差为4°，仍需稳定反馈；左右爪约11.63°/12.85°不会再因10°目标的微小偏差卡住。该设置仅用于全开，不改变手臂、闭爪或碰撞阈值。复位失败仍可预览，但不会开放确认抓取。

每次规划绑定本窗口、复位凭据、实例编号、商品ID及独立规划ID，保存在本次运行目录。改选饮料、重新识别、规划失败或停止后必须重新规划；确认按钮与弹窗显示具体饮料名称。执行器再次核验窗口/规划/商品身份，不从共享`last_plan.json`发起运动。

## 当前运动开放状态

**2026-09-16：按用户要求开放点击复位及“确认抓取”，仅为人工看护的实验模式，未进行实物抓取精度验收。**

使用最新标定`20260915_135708_706046`及靶标法线向内15mm的TCP补偿；不是沿世界Z轴一律减15mm。原标定质量报告未通过，保留相应验证标记为false，不伪造验收。`hardware_execution: true`加`supervised_experiment: true`显式开放看护实验；每次抓取有确认弹窗，仍要求本轮复位凭据、模型/标定哈希一致、真实反馈、完整路径检查。关闭实验模式则恢复原验证门禁。

复位使用独立的`reset_hardware_enabled: true`，不依赖视觉抓取校准门禁。执行器采用已检查的连续位置路径、反馈限速、固定身体检查、规划过期检查和界面心跳保护。启动时不创建运动桥，只有用户点击复位或确认通过门禁的抓取后创建。预检期间按停止也会取消待执行操作。

闭爪到位并稳定，或闭合已移动超过8°后持续稳定疑似接触物品，则保持夹爪并自动执行预检的抬起、收回路径，不再要求二次确认。完全未闭合、反馈异常、控制失效仍停止。尚无可靠的夹持力/物体在爪检测：记录`grip_success_verified: false`，流程完成不代表已夹稳，现场应留意掉落风险。

当前抓取关节速度上限120°/s、加速度上限720°/s²，相比上一版60°/s、180°/s²作2倍时间缩放（速度×2、加速度×4）。曲线斜率和曲率共同限制各关节速度/加速度。执行发送60Hz，反馈领先仍不超过3°，不积压过期目标。弯曲路径、电机反馈落后及安全等待会影响实际耗时，不承诺总耗时恰好减半。

复位独立使用速度/加速度上限70.2°/s、585°/s²，是上一版VR同档参数的2倍时间缩放，60Hz发送，领先仍不超过5°；不切换厂商SYNC会话。夹爪张开与双臂、头部回位并行；身体到位后稳定确认0.15s，夹爪仍稳定0.35s，两者都完成才发准备完成凭据。夹爪保持原单周期领先量与`gripper_speed_scale: 0.5`，通过桥频率30→60Hz提高推进频率，不叠加再次倍增开合步长，不增加夹持力。保留碰撞、轨迹偏离与故障保护，不重启服务。

`target_offset_torso_mm: [0,15,0]`是当前经验目标补偿：原来向右30mm，再按用户要求向左15mm，累计为向机器人右手侧15mm（不是替换成向左15mm）。实际URDF规划坐标系`Link_Waist_Yaw_to_Shoulder_Inner`中右肩Y=+0.1426m、左肩Y=−0.14269m，因此使用+Y。补偿不跟随相机、头部或手腕转向；识别目标加偏移后才做完整IK/路径检查。`last_geometry.json`记录原坐标、偏移及最终中心。原标定文件及另一个独立的15mm TCP参数不变，两项15mm含义/方向不同。改变工作区仍须验证。

抓取专用`GraspBridge`保留标定桥的通信、使能、控制权和无跟随保护，仅清理已进入原有容差的空闲目标看门狗；发送层不反复激活已到位或相同目标。真正未到位且5秒不动仍停止，并显示具体组及偏差，不通过删除保护来伪造复位成功。不修改手眼标定/综合控制中心的公共桥代码。

2026-09-16物品扩展版修正反馈受限推进：每周期只推进到当前反馈允许的位置，不再整帧丢弃并反复从零加速。保持抓取3°、复位5°领先限制。实际速度仍受电机反馈及路径曲率约束。同目录`motion_trace.jsonl`以2Hz记录规划速度上限、路径推进速度、实测速度与受限次数，供实机分析。

最新抓取执行版在用户确认执行后，通过现有保持式位置SYNC接口进入厂商同步动力学会话（`use_position_sync_session: true`），不切速度伺服、不直接访问CAN、不改公共电机参数。切换后仍校验姿态，入口失败则停止，不降级强行执行。正常退出先取消目标并保持实测位置，再释放SYNC回到ASYNC；崩溃由既有厂商1.5秒心跳保护兜底。复位流程不变。实际提速需要现场验证，不能把120°/s配置上限视为实测速度。

预抓点和收回点改为同时满足关节误差≤1°、模型TCP位置误差≤8mm、方向误差≤2°且稳定0.2秒才通过；抓取点和抬起点仍为关节误差≤0.35°且稳定0.35秒。末端误差是URDF/FK计算值，不代表实物精度。保留无跟随、碰撞、轨迹偏离、反馈和固定身体检查。重复的目标接收日志限制为每秒一次，警告及错误不抑制。

“停止运动”为软件停止，不是硬件急停。退出执行会保持，不自动松爪或复位。不要同时运行VR遥操、关节调试或手眼标定运动程序。

瓶身深度短时异常时，规划最多在3秒/10个不同图像帧内补采5帧合格数据，仍要求中心波动≤10mm。直径拟合、完整高度、时间配对和机器人停稳检查不放宽；持续不合格则拒绝规划。`/tmp/shelf306_*/depth_quality.json`记录有效帧数、录入直径和不合格原因，不再一帧反光就中止整轮。

SYNC会话中的关节无跟随与通信过期分别报告。无跟随仍立即保持并终止，不会自动清错/重新使能或闭爪。执行日志与`execution_result.json`保留具体关节、目标、桥输出及实测值，`motion_trace.jsonl`新增模型TCP残差；这些记录用于区分轨迹未发到位和真实电机未跟上，不能把亚度关节差简单当作可忽略的毫米误差。

## 边界

- 通用分割只给区域，不自动给商品名或可信抓取部位；须录入商品，袋口须人工选点。DINO参考图不能修复分割漏检。
- 瓶罐使用圆柱近似，其他实体使用已知厚度近似；必须尺寸正确、深度有效。透明、反光或密集遮挡会拒绝定位，不补造深度。袋口要求邻域有效深度与多帧稳定性；不覆盖细绳抓取和柔性物体摆动控制。
- 暂不建立桌面、货架和周边障碍物地图，也不进行支撑面检查。**不能保证避开桌面/货架，仅限已人工确认空旷的实验路径**；保留自碰撞、关节限位和携带物对机器人身体的保守包络。
- 水平工具方向来自现有机械模型定义，工具位置使用标定结果及旧靶标向内15mm补偿。夹爪开度改变可能影响真实TCP，必须实测。
- 模型IK残差不是手眼实物精度。不能承诺每个摆放位置都可达；第一版不搜索绕障或跨越奇异点的全局关节路径。
- 抓取期间不移动底盘、头部、腰腿、饮料；软件检查不替代实体急停或现场安全隔离。

## 柔性夹取

`orientation_relax_deg: 30.0`表示相对候选夹取姿态的最大整体旋转差，不是每个轴各30°。优先正向接近：先水平夹取，尝试原路径、两种肩肘冗余姿态偏好、向手臂外侧4/8cm的平滑绕行，再尝试柔性方向。均失败后按±5°、±10°、±15°……最大±60°逐档搜索，每档仍检查替代路径。角度指相对配置接近方向的偏移，不承诺连续角度下的全局最小解；总规划时间仍限制45秒。

绕行只改变到预抓点的路径，预抓点→抓取点仍为所选角度的直线；不改变瓶身目标中心或现有补偿。肩肘偏好只是IK次级目标，不能覆盖位置、方向、限位或碰撞约束。所有候选的四阶段及平滑插值均通过检查后才可执行。每次局部求解限定关节变化≤8°，困难路径段最多细分3层；没有绕过自碰撞检查。绕行也没有外部环境避障能力，必须确认其周围空间空旷并查看预览。

若已到达预抓点而失败发生在抓取/携带阶段，则跳过该方向下重复的预抓路径变体，优先寻找其他方向，避免无效重复。IK优化目标在允许方向偏差内部留0.25°数值余量，实际验收阈值不放宽。复杂目标可能需要更长搜索时间，超过总时限则拒绝执行，不返回未检查方案。

规划加速：使用同一份配置URDF的Pinocchio编译式FK及解析雅可比，避免每次IK迭代重复Python链计算和数值差分。四阶段IK及离散点碰撞检查先完成，再执行全部平滑插值检查；只有完整检查通过才返回可执行方案，不会边检查边运动。失败候选不再浪费前几段的密集插值验证。搜索角度、位姿容差、碰撞模型和最终检查密度不变。

抓住后以实际抓取姿态为基准，抬起/收回允许最多5°顺应，不再强扳回水平。预览显示本次采用水平或柔性方案及最大方向偏差。模型求解4mm容差不代表实物标定精度；超过物理工作范围仍拒绝，不移动底盘来补偿。

### 小角度抓取与收回解耦

如果小角度的预抓、抓取、抬起均已成功，仅收回段发生IK失败，先单独搜索收回姿态，
不立即扩大接近角度。收回中心仍按原方向直线后退20cm（或配置距离）；前6cm不额外转向，
随后通过平滑曲线绕真实竖直轴改变朝向，最多±30°，不主动增加瓶身倾斜。
方向误差仍相对新参考轨迹检查，所有限位、自碰撞、携带物包络和平滑插值检查保留。
这不是环境避障：6cm不是对货架净空的保证，执行前必须确认周围及收回空间。

只复用本次同一输入的前三阶段求解结果，完整路径仍重新验收；每次新规划清空缓存。
额外搜索全程最多12个候选，失败候选累计约2秒即停止追加，原45秒总时限保留。
界面分别显示“接近角度”和“收回转向”，收回转向不代表斜向插入物体。
