# 补录外观与物体位置纠偏

补录只扩充同一编号的识别图库，不覆盖第一帧的位姿、旧姿态或动作。
操作：选编号 → 给所选编号补录 → 框住完整物体 → 核对轮廓 → 确认保存。
可移动或转动物体后补录，不要求保持原位置，也不强制补录过渡面。

## 预览与任务执行

姿态默认为“只纠正位置”。先用全部有效视角识别物体并框出完整轮廓，
再计算初始参照到当前物体的位置变化。纹理足够时采用RGB-D配准；
纹理不能连回第一帧时，采用完整轮廓内分散的深度对应估计一致平移。
后者适用于完整轮廓相似、观察方向接近的场景，不能保证任意旋转或遮挡下定位。
这不是简单比较点云质心；透明瓶身的背景深度通过对应一致性剔除。

“位置＋朝向”仍需可靠的旋转证据，不能用上述平移估计冒充旋转。
补录已经认出、但深度或完整轮廓不足时，显示具体调整建议；不会将任意
补录照片的拍摄位置当作初始位置，也不会输出假零偏差。

纠偏预览显示完整物体轮廓、所用定位方法和XYZ偏移，模型路径检查沿用
现有动作链路。任务编排调用同一 visual_correct 入口；原始动作不改写。
未改变任何关节、夹爪、速度、使能或底层运动参数。

## 文件职责

- visual_multiview.py：补录存档、初始几何关联、全部视角识别选择。
- visual_shape_position.py：无类别的轮廓/深度位置估计；不控制硬件。
- visual_action_worker.py：分割、识别、定位、IK与预览路径计算。
- visual_action_panel.py / visual_reference_gallery.py：操作提示、预览和图片管理。
- test/test_visual_shape_position.py：平移、深度异常、局部轮廓、朝向隔离及参照不覆盖。

已有图片无需重新录入，图片库的“初始帧”仍为唯一基准。
