# 姿态与动作：物体参照纠偏

本功能基于已有“姿态与动作”、视觉后台和动作执行器扩展。无需商品类别、无需预先录入商品库。

## 示教

1. 打开“姿态与动作 → 调姿态”，展开顶部“物体参照”。填写参照名称。
2. 点击“取景 → 点物体记住”，点图像中有明显纹理的物体区域。界面显示分割轮廓。
3. 选择关联左手或右手，以及“只纠正位置”（默认）或“位置＋朝向”。
4. 用原关节/末端IK控件调整，或选择保存蓝色预览。点击“保存姿态”：系统重新定位参照，保存物体与该手末端的相对位姿。
5. 准备、收回等无需跟着物体移动的姿态，在保存前选择“不关联物体”。
6. “编动作”中加入已保存姿态；带“◎ 物体纠偏”的姿态才参与纠偏。连续交互的接近、接触、离开姿态应关联同一参照，不能只关联接触点而误以为整段路径会自动跟随。
7. 点击“定位参照并预览纠偏”；查看模型和页面顶部的XYZ变化量。“查看参照画面”显示实际匹配区域。普通“模型预演”对带参照的动作同样先重新定位。
8. 保存动作串。真机运行时再次拍摄、定位和计算；不会直接执行上次预览或覆盖原示教。

保存为抓取复位的目标仍是固定全身姿态，不会让全身复位跟随物体。

## 在抓取与任务流程调用

任务中继续选择“示教动作”及动作名称，不增加单独的补偿步骤。建议顺序：导航到位 → 身体高度调整 → 带物体参照的动作。后台自动执行：重新拍摄 → 特征/深度匹配 → 计算末端目标 → 所选手臂IK → 平滑轨迹检查 → 原动作执行器。

失败会停在当前步骤并显示具体原因；不会将失配当成零偏差，也不会改用未纠偏的旧动作。人工处理后重试会重新观察。抓取后的夹持交接、逐点关节到位后开合夹爪、零停顿平滑通过均沿用已有逻辑。纠偏不修改夹爪指令；示教中的主动开爪仍会执行。

## 原理与范围

保存的是带RGB、深度、分割区域和匹配特征的物体参照，以及关节反馈、相机安装关系、模型指纹与末端相对位姿。参照原点是可重复特征区域的锚点，不声称它是物体几何中心。执行时利用同一表面点的3D对应关系求刚体变化，不能用可见点云质心差代替。

位置＋朝向模式：`新末端 = 当前物体位姿 × 示教时物体到末端的变换`。只纠正位置模式仅平移示教末端，不把不可靠的绕轴旋转传给手腕。

当前版本用于姿态串的局部刚体纠偏（相对参照/示教位置200mm以内、姿态变化30°以内），固定该帧腰腿、另一侧手臂和夹爪目标，只对选中的七轴重新求解。原动作已有的腰腿变化仍属于该动作，不会被改为新的腰臂协同搜索。平滑过渡复用原C2轨迹，检查选中手臂的模型自碰撞；这不是环境障碍全局规划，也不是柔性衣物、门铰链或接触力自适应控制。

物体需要可重复纹理和有效深度，且原记录表面仍可见。纯色、透明反光、严重遮挡、外观完全相同的多个实例可能无法可靠匹配。请选择稳定的带标签区域；无法定位时调整视角或重新示教，不会猜测物体的朝向。

连续VR录制轨迹保持原时序，本次不把它稀疏化后纠偏。带参照姿态串统一在“姿态与动作”编辑，VR编辑器会提示跳转，防止普通关节微调留下过期的相对位姿。

## 冲突处理与数据

- 视觉命令复用唯一相机/模型进程，使用独立请求编号；不覆盖抓取选择、商品库或抓取计划。
- 计算与执行共用遥操/关节控制锁；纠偏执行还取得现有底盘互斥锁，核对从观察到执行的底盘位置。
- 取消操作写入独立取消标记；旧请求的成功响应不能触发运动。
- 模型/相机外参变化后要求重新记录参照；使能后姿态与已检查起点不一致时不播放旧轨迹。
- 原始姿态和动作不可被运行纠偏覆盖。参照文件按内容哈希存储，动作中保存绑定快照，改名或重拍同名物体不会悄悄改变已有动作。
- `data/fixed_actions/visual_references/*.npz`：RGB-D、mask、特征和参照元数据；迁移时与动作库一起复制。
- `manual_poses.json`：保持版本1和原`poses`，新增可选`visual_bindings`。
- `saved_joint_actions.yaml`：原动作记录增加可选逐帧`visual_bindings`，旧动作无该字段即可照常执行。
- 运行目录`visual_action_last_preview.json`：本次纠偏、误差、目标关节与底盘锚点，用于排查。

## 代码分工

| 文件 | 作用 |
|---|---|
| visual_reference.py | 参照文件、绑定格式、坐标变换、不可变快照 |
| visual_registration.py | RGB特征与配对深度、双向匹配、3D RANSAC |
| visual_action_worker.py | 复用视觉进程，关联姿态、当前定位、单臂IK和平滑路径检查 |
| visual_action_client.py | 独立请求编号、取消、超时及互斥协调 |
| visual_action_panel.py | 拍照点选、关联选项和匹配画面 |
| pose_workspace.py / pose_workspace_data.py | 姿态保存、动作组合、纠偏预演 |
| teaching_motion.py / teaching_library.py / task_flow.py | 保存和传递可选绑定，不破坏旧格式 |
| teaching_studio.py / action_studio.py | 任务与手动执行共用入口、原执行器、起点及底盘检查 |
| teaching_composer.py | 防止VR编辑器覆盖带参照动作 |

不新增运动控制器、不修改原厂电机参数、不重启机械臂服务；复用现有SAM2、OpenCV、NumPy、SciPy、Pinocchio环境，无在线下载依赖。
